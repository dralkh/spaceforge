# Release artwork

The images and the preview film referenced by the top-level `README.md`. Everything here is
generated by the tooling in `media/spaceforge-preview/` (git-ignored scratch): the panels are
tight crops of the real plugin running in Obsidian, the typography is drawn in code with Inter,
and nothing is model-generated imagery.

| File | What it is | Rebuild with |
|---|---|---|
| `spaceforge-banner.png` | README banner (2400×1200) | `make-marketing-images.py` |
| `spaceforge-capabilities.png` | Capability card, six real UI panels (2400×1930) | `make-marketing-images.py` |
| `spaceforge-preview-poster.png` | Poster — the film's Study scene (1920×1080) | `make-marketing-images.py` |
| `spaceforge-preview-thumbnail.png` | YouTube thumbnail (1280×720) | `make-marketing-images.py` |
| `spaceforge-preview-1440p.mp4` | **The 1:50 product film** — 2560×1440, narration + original music | `render.py --stage finish` |

The film is recorded from the plugin itself (an isolated Obsidian instance driven over CDP) with a
seeded example vault; its AI scenes run against a local OpenAI-compatible endpoint that returns
authored responses in the exact shapes the plugin expects. Captions ship beside it in
`media/spaceforge-preview/output/` (`captions.en.srt`/`.vtt`, `captions.ar.srt`/`.vtt`).

To rebuild everything:

```sh
cd media/spaceforge-preview
node scripts/seed-demo.mjs && node scripts/seed-decks.mjs
node scripts/capture-demo.mjs && node scripts/capture-settings.mjs && node scripts/capture-features.mjs
node scripts/capture-calendar.mjs --width=1050 --zoom=0.85
node scripts/capture-fixes2.mjs --only S24,S25
node scripts/capture-study.mjs
node scripts/capture-settings-cli.mjs
/usr/bin/python3 scripts/build-footage.py
/usr/bin/python3 scripts/narration.py && /usr/bin/python3 scripts/arabic.py
/usr/bin/python3 scripts/make-edit.py
/usr/bin/python3 scripts/render.py --stage clips && /usr/bin/python3 scripts/render.py --stage finish
/usr/bin/python3 scripts/make-marketing-images.py
/usr/bin/python3 scripts/verify.py
cp output/spaceforge-preview-master-1440p.mp4 ../../assets/spaceforge-preview-1440p.mp4
```
